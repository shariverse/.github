# Shariverse（シャリバース）

**ネタは宇宙、土台はシャリ。**

Shariverse は、iOS・Android 向けアプリを開発するチームです。
友人同士で「作ってみたい」を持ち寄り、小さなアプリを 1 つずつ形にして届けています。

## 私たちについて

- 友人同士で、アプリ開発を楽しむチームです
- アプリも、オタク文化も、寿司も好きです
- 本業とは別に、自分たちが「使いたい」「作りたい」と思ったものを作っています

## 目的

- アイデア（ネタ）を出し合い、使って楽しいアプリに仕上げて公開する
- iOS と Android の両方に届ける
- 小さく作って、試して、手を入れ続ける
- 作る過程そのものを、楽しむ

## 名前の由来

**Shari（寿司のシャリ）＋ universe（宇宙）**

シャリは、ネタを乗せる土台です。私たちにとってのシャリは、みんなのアイデアを受け止めてアプリにする場所。その土台の上に、宇宙のようにアプリが広がっていく、という意味を込めています。

アプリを 1 つ出すたびに、1 貫。握るたびに、星が増えていきます。
